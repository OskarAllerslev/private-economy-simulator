# Private Economy Simulator

A Java simulation modeling the dynamics of a private economy.

## Prerequisites

- Java 21 or higher

## Getting Started

### Run the Application

Using the Gradle wrapper:

**On Windows:**
```powershell
.\gradlew.bat run
```

**On Linux / macOS:**
```bash
./gradlew run
```

### Build and Test

```bash
./gradlew build
```

To run tests:

```bash
./gradlew test
```
